# Extension Icons

This extension requires the following icon files:

- `icon16.png` (16x16 pixels)
- `icon48.png` (48x48 pixels)
- `icon128.png` (128x128 pixels)

## Creating Icons

You can create these icons using any image editor (like Photoshop, GIMP, or Figma). The icons should be:

1. Square in shape
2. PNG format with transparency
3. Simple and recognizable at small sizes
4. Ideally using the primary blue color (#4a6cf7) from the extension theme

## Placeholder Icons

Until you create your own icons, you can use simple blue square icons or download free icons from resources like:

- [Flaticon](https://www.flaticon.com/)
- [Iconfinder](https://www.iconfinder.com/)
- [Material Icons](https://fonts.google.com/icons)

## Naming Convention

Make sure to save your icons with the exact filenames mentioned above:
- `icon16.png`
- `icon48.png`
- `icon128.png`

And place them in this `/images` directory.
